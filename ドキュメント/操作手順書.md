## 1. 準備

1. フォルダ `読書` を開く
2. `python -m venv .venv` を実行する
3. `.\.venv\Scripts\python -m pip install -r requirements.txt` を実行する
4. `.\.venv\Scripts\python -m uvicorn app:app --host 127.0.0.1 --port 8000` を実行する
5. ブラウザで http://127.0.0.1:8000 を開く

止めるときは、起動した画面で `Ctrl+C` を押します。

## 2. 登録とログイン

1. 名前とパスワードを入れる
2. 初めてなら「登録」を押す。登録済みなら「ログイン」を押す
3. 名前が表示されたら、本を記録できる
4. 「ログアウト」を押すと、一覧は隠れる

名前は空白なしで1から32文字です。パスワードは8から64文字です。

## 3. 本

1. 題名、著者、状態、メモを入れて「追加」を押す
2. 一覧の値を変えて「保存」を押すと、その本が更新される
3. 「削除」を押して確認すると、その本が消える
4. ページを開き直しても、ログインしていれば同じ一覧から続く

状態は、読みたい、読んでいる、読み終わったです。別のアカウントでログインすると、別の一覧になります。

## 4. AWS

EC2 へ載せる定義は「AWSデプロイガイド」にあります。インスタンスは起動していません。いま開くときは、この資料の第1章です。

## 5. プロトタイプ

サーバを起動せずに画面を見るときは、`prototype/index.html` をブラウザで開きます。登録、ログイン、本の追加、更新、削除ができます。記録とパスワードは、そのブラウザの localStorage に残ります。SQLite の `reading.db` には書きません。本実装を開くときは、第1章です。
