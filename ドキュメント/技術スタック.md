この資料は、言語、フレームワーク、データベース、実行環境を分けるための選定です。Cloudflare Workers と Durable Objects は実行環境です。言語でも、フレームワークでも、データベース製品でもありません。

フロントエンドの言語は JavaScript です。画面は Vue のコンポーネントで書き、Nuxt がブラウザ用のファイルを生成します。Nuxt は Vue のフレームワークです。バックエンドの言語は JavaScript、フレームワークは Hono です。データベースの言語は SQL、製品は SQLite です。Hono は Cloudflare Workers の上で動きます。SQLite は Durable Object のストレージとして動きます。本のデータベース製品は SQLite です。確認用の RDS は PostgreSQL で、EC2 からだけ接続します。手元の起動に Wrangler を使います。

EC2 は 2026年10月26日に起動し、同じ日にアプリを載せています。EC2 の中では Wrangler が Hono と Durable Object の SQLite を動かします。入口は nginx の 80 番で、この PC だけが開けます。

パスワードは PBKDF2-SHA-256 でハッシュしてから `users` に残します。平文では残しません。

## 1. 採用するもの

| 層 | 言語 | フレームワークまたは製品 | 実行環境 | 場所 |
|---|---|---|---|---|
| フロントエンド | JavaScript | Vue 3、Nuxt | ブラウザ | ソースは `frontend/app/app.vue` と `frontend/app/components`。見た目は `frontend/app/assets/main.css`。Nuxt が `frontend/.output/public` を生成し、Wrangler が配信する |
| バックエンド | JavaScript | Hono 4.13.13 | Cloudflare Workers。`127.0.0.1:8787` | `backend/worker.js` が `/api/` を渡す。経路は `durable-object/reading.js` |

| 手元の起動 | | Wrangler 4.45.0 | このパソコン | `wrangler.toml`、`package.json` |

## 2. 起動

Node.js を使います。

```powershell
cd $HOME\OneDrive\Desktop\読書
npm install
npm run dev
```

`npm install` は、画面の Vue と Nuxt も入れます。`npm run dev` は、Nuxt で静的ファイルを生成してから Wrangler を起動します。ブラウザで http://127.0.0.1:8787 を開きます。止めるときは `Ctrl+C` です。

画面のソースを直しながら見るときは、一方で `npm run dev:api`、もう一方で `npm run dev:web` を実行し、http://127.0.0.1:3000 を開きます。`/api` は 8787 へ渡します。

## 3. 採用しないもの

| 採用しないもの | 理由 |
|---|---|
| 画面を1枚の HTML に直書きすること | 画面は Vue のコンポーネント。生成は Nuxt |
| Python、FastAPI、Django、Flask | バックエンドの言語は JavaScript、フレームワークは Hono |
| 読書の記録を RDS に移すこと | 本のデータベース製品は SQLite |
| ファイル `reading.db` | SQLite は Durable Object のストレージ |
