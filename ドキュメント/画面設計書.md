| 項目 | 内容 |
|---|---|
| 文書名 | 画面設計書 |
| 対象システム | 読書記録 |
| 版 | 1.0 |
| 作成日 | 2026年10月26日 |
| 作成者 | nsb |
| 関連資料 | 要件定義書、用語定義書、機能要件、機能要件定義書、画面見取り図、操作手順書、ER図、ユースケース、データベース設計、技術スタック、`frontend/index.html` |
| 目的 | 画面の部品を、位置、表示、押したときの動きまで表にする |

この資料は、画面の設計です。配置の図は「画面見取り図」です。操作の手順は「操作手順書」です。機能の定義は「機能要件定義書」です。確認用の一覧は「機能要件」です。言葉の意味は「用語定義書」に従います。番号の正は「要件定義書」の「作ること」です。

新しい部品と、新しい操作は、この資料では足しません。作らないことの正は「要件定義書」の「作らないこと」です。

画面は1枚です。画面IDは SCR-01 です。ファイルは `frontend/index.html` です。見た目は、そのファイルの `<style>` です。別の画面は開きません。

## 1. 読み方

| 項目 | 意味 |
|---|---|
| 画面ID | 画面を区別する番号。この版では SCR-01 だけ |
| 部品番号 | この資料の中で、部品を引く番号。機能の番号とは別に振る |
| 初期表示 | ページを開いた直後、ログインが無いときの見え方 |
| 操作 | その部品を押したときの動き |

部品番号は、P-1 から始めます。機能の番号 A-1 から B-4 は、要件定義書のままです。

## 2. 画面一覧

| 画面ID | 画面名 | ファイル | 内容 |
|---|---|---|---|
| SCR-01 | 読書記録 | `frontend/index.html` | 見出し、説明、ログイン欄。ログイン後は名前、ログアウト、追加欄、一覧 |

開き直したとき、セッションが残っていればログイン後の表示から続きます。残っていなければ、ログイン欄から始まります。

## 3. SCR-01 の領域

| 領域 | 範囲 | 押したとき | 機能 |
|---|---|---|---|
| 見出しと説明 | 画面の上 | 押しても、本は変わらない | |
| ログイン欄 | ログイン前の、名前、パスワード、ログイン、登録 | 登録またはログイン | A-1、A-2 |
| ログイン後の見出し行 | 名前とログアウト | ログアウトすると、ログイン欄に戻る | A-3 |
| 追加欄 | 題名、著者、状態、メモ、追加 | 1件追加する | B-1 |
| 一覧 | 空の案内、または本のカード | 保存で更新、削除で確認して消す | B-2、B-3、B-4 |

ログイン欄と、ログイン後の領域は、同時には出しません。

## 5. 開いたときの状態

| 部品 | ログインが無いとき | セッションが残っているとき |
|---|---|---|
| 見出し、説明 | 出る | 出る |
| ログイン欄 | 出る | 隠す |
| 利用者名、ログアウト | 隠す | 出る |
| 追加欄、一覧 | 隠す | 出る |
| 空の案内 | 隠す | 0件のときだけ出る |

## 6. 操作と画面の変化

| 操作 | 変わるもの | 変化 | 変わらないもの |
|---|---|---|---|
| 登録する | ログイン欄、一覧 | ログイン後の表示になる。一覧は0件 | 他のアカウントの本 |
| ログインする | ログイン欄、一覧 | 自分の本が新しい順に出る | 他のアカウントの本 |
| 登録またはログインに失敗する | ログインの案内 | 理由の文に変わる | 一覧は出たままにしない |
| ログアウトする | ログイン欄、一覧 | 一覧を隠し、ログイン欄に戻す | SQLite の本の行 |
| 追加する | 一覧、追加欄 | 先頭にカードが増える。追加欄は空に戻る | 他の人の本 |
| 保存する | そのカード | 入れた値になる。開き直しても残る | 他のカード |
| 削除を確認する | そのカード | 一覧から消える | 他のカード |
| 削除を取り消す | なし | 何も消えない | そのカード |
| ページを開き直す | 一覧 | セッションが残っていれば、同じ一覧から続く | 本の行 |

ログインに失敗したときの文は、次です。同じ名前は「その名前は使われています。」です。名前またはパスワードが違うときは「名前またはパスワードが違います。」です。文字数や空白が約束と違うときは「名前は空白なしで1から32文字です。パスワードは8から64文字です。」です。

## 7. 置かない部品

この画面には、次を置きません。

- 表紙画像
- 貸出
- 評価の点数
- 他の人の本
- 別の画面へ進む部品
