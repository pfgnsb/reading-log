## 1. 採用するもの

| 層 | 言語 | フレームワークまたは製品 | 実行環境 | 場所 |
|---|---|---|---|---|
| フロントエンド | HTML、CSS、JavaScript | なし | ブラウザ | `templates/index.html`、`static/style.css` |
| バックエンド | Python 3.12 | FastAPI 0.115 | Uvicorn 0.34。`127.0.0.1:8000` | `app.py` |
| データベース | SQL | SQLite | ファイル `reading.db` | `db.py` |

Uvicorn は FastAPI を動かすためのサーバです。言語でもフレームワークでもありません。SQLite のファイルは、アプリを起動したフォルダにできます。製品は SQLite です。PostgreSQL と RDS は使いません。

EC2 と nginx は、あとに載せるときの実行環境と入口です。どちらも言語、フレームワーク、データベースではありません。インスタンスはまだ起動していません。手順は「AWSデプロイガイド」です。

パスワードは PBKDF2-SHA-256 でハッシュしてから `users` に残します。平文では残しません。

## 2. 起動

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

ブラウザで http://127.0.0.1:8000 を開きます。

## 3. 採用しないもの

| 採用しないもの | 理由 |
|---|---|
| React、Vue | 画面は HTML、CSS、JavaScript |
| Django、Flask | バックエンドのフレームワークは FastAPI |
| PostgreSQL、MySQL、RDS | データベースの製品は SQLite |
| いま EC2 を起動すること | 定義だけ置く。起動は別の指示を待つ |
