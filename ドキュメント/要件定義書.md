| 目的 | 何を作るか、何を作らないかを決める |

読書記録は、登録した人が自分の本を残すアプリです。言語は Python、フレームワークは FastAPI、データベースは SQLite です。

## 1. 利用者

| 項目 | 内容 |
|---|---|
| 利用者 | 登録した人 |
| ログイン | あり。登録、ログイン、ログアウト |
| 共有 | しない。他の人の本は見えない |
| 動かす場所 | いまは手元のパソコン。`http://127.0.0.1:8000`。EC2 の定義はあるが、起動していない |

## 2. 作ること

| No. | できること | 詳細 |
|---|---|---|
| A-1 | 登録する | 名前とパスワードでアカウントを作る。その場でログインする |
| A-2 | ログインする | 名前とパスワードが一致すると、自分の本を扱える |
| A-3 | ログアウトする | ログアウトすると、もう一度ログインするまで本は見えない |
| B-1 | 本を追加する | 題名、著者、状態、メモを1件残す |
| B-2 | 一覧を見る | 自分の本だけを新しい順に出す |
| B-3 | 本を直す | 題名、著者、状態、メモを更新する |
| B-4 | 本を削除する | 自分の本を1件消す |

状態は、読みたい、読んでいる、読み終わったの3つです。

## 3. 作らないこと

| 項目 | 理由 |
|---|---|
| 他の人の本を見ること | 記録はアカウントごとに分ける |
| 表紙画像、貸出、評価の点数 | この版で残すのは題名、著者、状態、メモ |
| 全世界への公開 | 起動したあとも、この PC のアドレスからだけ開ける |
| RDS、PostgreSQL | データベースの製品は SQLite |
| AWS の起動 | 定義だけ置く。`terraform apply` は、起動してよいと言われるまで実行しない |

## 4. 完成の定義

1. 登録またはログインするまで、本の一覧は出ない
2. 本を追加でき、一覧に出る
3. 状態とメモを直し、開き直しても残る
4. 削除すると、その本は一覧から消える
5. 別のアカウントでは、先のアカウントの本が見えない
6. ログアウトすると、もう一度ログインするまで本は出ない
