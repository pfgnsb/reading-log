# 用語定義書

| 項目 | 内容 |
|---|---|
| 文書名 | 用語定義書 |
| 対象システム | 読書記録 |
| 版 | 1.0 |
| 作成日 | 2026年10月26日 |
| 作成者 | nsb |
| 関連資料 | ドキュメント一覧、要件定義書、機能要件、機能要件定義書、非機能要件、画面見取り図、画面設計書、ER図、ユースケース、データベース設計 |
| 目的 | このシステムで使う言葉の意味を、一箇所に定める |

この資料は、言葉の意味の正です。資料の入口は「ドキュメント一覧」です。何を作るか、何を作らないかは「要件定義書」に従います。番号の正は「要件定義書」の「作ること」です。

新しい操作は、この資料では足しません。表にない動きを、言葉の意味から足しません。

## 1. 読み方

| 項目 | 意味 |
|---|---|
| 番号 | この資料の中で、言葉を引く番号 |
| 言葉 | 資料と画面で使う呼び方 |
| 意味 | その言葉が指すもの |

同じ言葉を、別の意味では使いません。

## 2. 人

| 番号 | 言葉 | 意味 |
|---|---|---|
| 1 | 利用者 | 登録した人。自分の本だけを残す |
| 2 | アカウント | 利用者1人。SQLite の `users` の1行 |
| 3 | 名前 | アカウントを区別する文字列。空白なしで1から32文字。重複しない |
| 4 | パスワード | ログインに使う文字列。8から64文字。平文では残さない |
| 5 | セッション | ログイン中のしるし。Cookie `session` と、SQLite の `sessions` の1行。発行から7日 |
| 6 | ログイン | 名前とパスワードが一致し、自分の本を扱える状態 |
| 7 | ログアウト | セッションを消し、もう一度ログインするまで本を出さないこと |

## 3. 本

| 番号 | 言葉 | 意味 |
|---|---|---|
| 8 | 本 | 利用者が残す1件。題名、著者、状態、メモを持つ。必ず1人の利用者に属する |
| 9 | 題名 | 本の名前。前後の空白を除いて1から80文字 |
| 10 | 著者 | 本を書いた人の名前。前後の空白を除いて1から80文字 |
| 11 | 状態 | 読みたい、読んでいる、読み終わったの3つのどれか。保存する値は `want`、`reading`、`done` |
| 12 | 読みたい | 状態の1つ。値は `want` |
| 13 | 読んでいる | 状態の1つ。値は `reading` |
| 14 | 読み終わった | 状態の1つ。値は `done` |
| 15 | メモ | 本に添える文章。空でもよい。400文字まで |
| 16 | 一覧 | ログインした人の本だけを、新しい順に並べたもの。新しい順は、後から追加した行が先 |
| 17 | 新しい順 | `books.id` の大きい順。後から追加した本が上に出る |

## 4. 画面

| 番号 | 言葉 | 意味 |
|---|---|---|
| 18 | 画面 | `templates/index.html` の1枚。別の画面は開かない。画面IDは SCR-01 |
| 19 | ログイン欄 | 画面の上の、名前、パスワード、ログイン、登録。ログインすると隠れる |
| 20 | 追加欄 | ログインしたあとに出す、題名、著者、状態、メモ、追加 |
| 21 | 本のカード | 一覧の1件。題名、著者、状態、メモ、保存、削除を持つ |
| 22 | 空の案内 | 自分の本が0件のときの「まだ本がありません。」 |
