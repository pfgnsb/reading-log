| 関連資料 | 要件定義書、用語定義書、機能要件、機能要件定義書、画面見取り図、ER図、`frontend/app/app.vue` |
| 目的 | 利用者が達成することを、流れで示す |

この資料は、利用の流れです。言葉の意味は「用語定義書」に従います。番号の正は「要件定義書」の「作ること」です。関係の図は「ER図」です。

新しい操作は、この資料では足しません。画面は1枚です。ファイルは `frontend/app/app.vue` です。

## 1. アクター

| アクター | 役割 |
|---|---|
| 利用者 | 登録した人。ログインしてから、自分の本を残す |

## 2. ユースケース図

```mermaid
flowchart LR
  user[利用者]
  user --> uc1[UC-1 画面を開く]
  user --> uc2[UC-2 登録する]
  user --> uc3[UC-3 ログインする]
  user --> uc4[UC-4 ログアウトする]
  user --> uc5[UC-5 本を追加する]
  user --> uc6[UC-6 一覧を見る]
  user --> uc7[UC-7 本を直す]
  user --> uc8[UC-8 本を削除する]
```

## 3. UC-1 画面を開く

| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 対応する機能 | A-2、B-2 |
| 事前条件 | 手元で Wrangler が `127.0.0.1:8787` を待っている |
| 事後条件 | ログインが無ければ、ログイン欄だけが見える。ログインが残っていれば、自分の本の一覧が見える |

```mermaid
flowchart TD
  a["http://127.0.0.1:8787 を開く"] --> b["GET /api/me を送る"]
  b --> c{ログインしているか}
  c -->|いいえ| d[ログイン欄を出す]
  c -->|はい| e[名前と、自分の本の一覧を出す]
```

## 4. UC-2 登録する

| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 対応する機能 | A-1、B-2 |
| 事前条件 | ログインしていない。名前はまだ使われていない |
| 事後条件 | ログインしている。一覧は0件から始まる |

```mermaid
flowchart TD
  a[名前とパスワードを入れる] --> b[登録を押す]
  b --> c{名前とパスワードは約束どおりか}
  c -->|いいえ| d[一覧は出さない]
  c -->|はい| e{同じ名前があるか}
  e -->|ある| f[その名前は使われていると出す]
  e -->|無い| g[アカウントを作り、ログインする]
```

## 5. UC-3 ログインする

| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 対応する機能 | A-2、B-2 |
| 事前条件 | その名前が登録されている |
| 事後条件 | 自分の本だけが見える |

```mermaid
flowchart TD
  a[名前とパスワードを入れる] --> b[ログインを押す]
  b --> c{一致するか}
  c -->|いいえ| d[一覧は出さない]
  c -->|はい| e[自分の本を新しい順に出す]
```

## 6. UC-4 ログアウトする

| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 対応する機能 | A-3 |
| 事前条件 | ログインしている |
| 事後条件 | ログイン欄に戻る。本の行は SQLite に残る |

```mermaid
flowchart TD
  a[ログアウトを押す] --> b[セッションと Cookie を消す]
  b --> c[一覧を隠す]
```

## 7. UC-5 本を追加する

| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 対応する機能 | B-1、B-2 |
| 事前条件 | ログインしている |
| 事後条件 | その本が一覧の先頭に出る |

```mermaid
flowchart TD
  a[題名、著者、状態、メモを入れる] --> b[追加を押す]
  b --> c{題名と著者があるか}
  c -->|いいえ| d[追加しない]
  c -->|はい| e[1件残し、一覧の先頭に出す]
```

## 8. UC-6 一覧を見る

| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 対応する機能 | B-2 |
| 事前条件 | ログインしている |
| 事後条件 | 自分の本だけが、新しい順に見える。0件なら空の案内が出る |

```mermaid
flowchart TD
  a[ログインが済んでいる] --> b[自分の行だけを読む]
  b --> c{件数}
  c -->|0| d[まだ本がありません、と出す]
  c -->|1以上| e[新しい順にカードを出す]
```

## 9. UC-7 本を直す

| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 対応する機能 | B-3 |
| 事前条件 | ログインしている。そのカードが自分の本である |
| 事後条件 | 題名、著者、状態、メモが更新され、開き直しても残る |

```mermaid
flowchart TD
  a[カードの値を変える] --> b[保存を押す]
  b --> c{自分の本で、値が約束どおりか}
  c -->|いいえ| d[更新しない]
  c -->|はい| e[行を更新し、一覧を出し直す]
```

## 10. UC-8 本を削除する

| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 対応する機能 | B-4、B-2 |
| 事前条件 | ログインしている。そのカードが自分の本である |
| 事後条件 | 確認した本だけが一覧から消える |

```mermaid
flowchart TD
  a[削除を押す] --> b{確認するか}
  b -->|取り消す| c[何もしない]
  b -->|確認する| d[その1件を消す]
  d --> e[一覧から除く]
```
