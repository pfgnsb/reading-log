| 目的 | 機能以外の約束を、環境、残し方、費用、入力の長さまで1枚にまとめる |

この資料は、機能以外の約束です。資料の入口は「ドキュメント一覧」です。できることの番号の正は「要件定義書」の「作ること」です。言葉の意味は「用語定義書」に従います。

新しい操作は、この資料では足しません。新しい数字も足しません。作らないことの正は「要件定義書」の「作らないこと」です。

画面は1枚です。ファイルは `templates/index.html` です。データベースは SQLite の `reading.db` です。

## 1. 読み方

| 項目 | 意味 |
|---|---|
| 環境 | 誰が、どこで、どう開くか |
| 残し方 | ページを閉じたあとに、何が残るか |
| 費用 | お金と、有料のサービス |
| 入力の長さ | 名前、パスワード、題名、著者、メモの文字数 |

## 2. 環境

| 項目 | 約束 |
|---|---|
| 利用者 | 登録した人 |
| ログイン | あり。登録、ログイン、ログアウト。ログインしないと本は出ない |
| 他の人との共有 | 同じ行は共有しない。アカウントごとに分かれる |
| 動かす場所 | いまは手元の `http://127.0.0.1:8000`。EC2 の定義はある。インスタンスは起動していない |
| フロントエンド | `templates/index.html` と `static/style.css`。言語は HTML、CSS、JavaScript。フレームワークはない |
| バックエンド | 言語は Python 3.12。フレームワークは FastAPI。ファイルは `app.py`。実行環境は Uvicorn。`127.0.0.1` の 8000 番 |
| データベース | 言語は SQL。製品は SQLite。ファイルは `reading.db`。読み書きは `db.py` |
| インターネット | 手元は、このパソコンの中だけで開く。EC2 を起動したあとも、入れるのはこの PC だけ |
| 画面の数 | 1枚。別の画面は開かない |

版の正は「技術スタック」です。EC2 へ載せる手順は「AWSデプロイガイド」です。いまは実行しません。

## 3. 残し方

本は、ログインした人の SQLite の行に残します。PostgreSQL と RDS は置きません。パスワードは PBKDF2-SHA-256 のハッシュだけを残します。平文は残しません。

| 閉じる前 | 開き直したあと |
|---|---|
| ログインしている | セッションが7日以内なら、同じ一覧から続く |
| ログアウトした | ログイン欄に戻る。本の行は残る |
| 本を追加、更新、削除した | その結果が残る |
| セッションが7日を過ぎた | ログインしていないものとして扱う |

Cookie `session` は HttpOnly、SameSite=Lax、Path=/、有効期限は7日です。

## 4. 費用

| 項目 | 約束 |
|---|---|
| 手元の起動 | 追加の購入はしない |
| データベース | SQLite。RDS は作らない |
| AWS | 定義だけ置く。`terraform apply` は、起動してよいと言われるまで実行しない。起動していないあいだ、この定義で減り続けるクレジットはない |

## 5. 入力の長さ

| 項目 | 約束 |
|---|---|
| 名前 | 空白なしで1から32文字 |
| パスワード | 8から64文字 |
| 題名 | 前後の空白を除いて1から80文字 |
| 著者 | 前後の空白を除いて1から80文字 |
| メモ | 空でもよい。400文字まで |
| 状態 | `want`、`reading`、`done` のどれか |
