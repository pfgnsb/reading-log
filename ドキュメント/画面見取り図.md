この資料は、画面の配置の図です。部品の表は「画面設計書」です。作る機能の範囲は「要件定義書」に従います。番号の正は「要件定義書」の「作ること」です。言葉の意味は「用語定義書」に従います。

画面は1枚です。画面IDは SCR-01 です。ファイルは `frontend/index.html` です。別の画面は開きません。図の寸法は、実物どおりではありません。

## 1. ログイン前（SCR-01）

見出しと説明は、常に出します。ログインするまで、本の追加欄と一覧は出しません。

```text
+----------------------------------------------+
| 読書記録                                      |
| 読んだ本と、これから読む本を残します。          |
+----------------------------------------------+
| 名前 [          ]  パスワード [          ]   |
| [ログイン]  [登録]                            |
| ログインすると、自分の本を記録できます。        |
+----------------------------------------------+
```

地の色は薄い灰色です。欄の地は白です。ログインは濃いボタン、登録は白地のボタンです。

## 2. ログイン後（同じ SCR-01）

ログイン欄は隠れます。名前とログアウト、追加欄、一覧が出ます。

```text
+----------------------------------------------+
| 読書記録                                      |
| 読んだ本と、これから読む本を残します。          |
+----------------------------------------------+
| 名前                              [ログアウト] |
+----------------------------------------------+
| 題名 [        ]  著者 [        ]             |
| 状態 [読みたい v]                             |
| メモ [                          ]  [追加]    |
+----------------------------------------------+
| まだ本がありません。     （0件のときだけ）     |
| +------------------------------------------+ |
| | 題名 [      ]  著者 [      ]             | |
| | 状態 [読んでいる v]  メモ [          ]   | |
| | [保存]  [削除]                            | |
| +------------------------------------------+ |
+----------------------------------------------+
```

本が1件以上あるときは、空の案内は隠します。カードは新しい順に、上から並べます。状態の選択肢は、読みたい、読んでいる、読み終わったです。

削除を押すと、この画面の上に「この本を削除しますか？」と確認が出ます。確認を取り消すと、カードはそのままです。

## 3. 図の部品

| 図の印 | 部品 | 内容 | 機能 |
|---|---|---|---|
| 読書記録 | 見出し | 画面の上。常に出る | |
| 説明 | 説明 | 「読んだ本と、これから読む本を残します。」 | |
| 名前、パスワード | ログイン欄 | ログイン前だけ。登録とログイン | A-1、A-2 |
| ログアウト | ログアウト | ログイン後だけ | A-3 |
| 題名、著者、状態、メモ、追加 | 追加欄 | ログイン後だけ | B-1 |
| まだ本がありません | 空の案内 | 自分の本が0件のとき | B-2 |
| カード | 本のカード | 1件につき1つ。保存と削除 | B-2、B-3、B-4 |

いまの `frontend/index.html` は、この図のとおりです。
